원본 뭉치를 역추적 가능한 코퍼스로 바꾼다: 판별 → 변환 → 품질 게이트 → 로컬 정본 → (지시 시) 미러 → 적재 → 스모크 질의 → 검증.

## Goal

원본 데이터를 **AI가 검색할 수 있는 코퍼스**로 만든다. 그것이 유일한 임무다.

**검색된다는 것은 값이 맞다는 증거가 아니다.** 열이 밀린 값도, 글리프가 깨져 잡음이 된
값도, 환각으로 지어낸 전사문도 똑같이 색인되고 똑같이 검색된다. 그래서 진척은 적재
건수가 아니라 **원본까지 되짚을 수 있는 값의 수**다. 변환기가 성공 코드로 끝났다는 것도
증거가 아니다 — 내용이 게이트를 통과해야 성공이다.

배치의 정산 버킷: **발견 = 적재 + 실패 + 건너뜀 + 격리 + 보류.**

- **발견** = 이번 배치가 집은 파일 수(≤50). 소스에 더 남았으면 정산에 섞지 말고
  "다음 배치"로 보고한다.
- **적재** = 로컬 정본 저장 + 코퍼스 적재 + 스모크 질의 적중까지 성공한 문서.
- **실패** = 형식 판별 실패(확장자 위장 포함)·변환 실패·적재 실패. 3회 재시도가 소진된
  단위도 여기(사유 `재시도 소진`). 목록에 경로와 사유를 그대로 남긴다.
- **건너뜀** = 의도적 비처리. 사유 명기: `민감`(확정) | `고객사` | `불변`(재적재 시 원본
  해시·변환기 버전이 이전 배치와 동일 — 색인이 증거).
- **격리** = 변환은 끝났지만 품질 게이트 미달(글리프 깨짐, 저신뢰 OCR/STT 등).
  코퍼스에 넣지 않고 `quarantine/`에 보존한다 — 도구가 좋아지면 재시도할 원본 목록이다.
- **보류** = 민감 자동 스캔이 플래그했으나 사람 판정 대기. 미러·적재를 멈춘다.
  사람이 판정하면 적재 또는 건너뜀으로 옮긴다.

미러는 별도 버킷(성공/실패)으로 따로 센다 — 미러 실패는 적재 실패가 아니다
(로컬 정본은 이미 존재한다).

## 저장 계층

로컬이 항상 정본(1차)이고, 미러(2차)는 지시가 있을 때만 만든다. 어느 미러가 실패해도
로컬 정본은 남는다.

| 층 | 조건 | 위치 |
|---|---|---|
| **로컬 (정본, 항상)** | 무조건 | 도구 설정이 정하는 코퍼스 기준 폴더 아래 `ingestiger/` — 경로를 직접 지어내지 않는다. 기준 폴더 설정이 없으면 호출자에게 묻는다 |
| **구글 드라이브 (미러)** | 지시에 공유·백업 의도가 있을 때 | 지시받은 드라이브 폴더에 로컬 정본 폴더 구조 그대로. 호출 환경에 배선된 드라이브 도구를 쓴다 — 없으면 미러 실패로 세고 지어내지 않는다 |
| **선택 DB (미러)** | 지시에 DB 적재 의도가 있을 때 | 지시받은 DB의 코퍼스 스키마. 스키마 정의 파일이 유일한 기준이며, **스키마를 만들거나 바꾸지 않는다** — 없거나 다르면 멈추고 올린다 |

로컬 정본 폴더 구조 — 사람이 폴더만 열어도 무엇이 들어왔는지 보여야 한다:

```
<기준 폴더>/ingestiger/
├── index.md          # 위키형 색인: 문서당 1행 (제목 · 원본 경로 · content_hash · 변환기@버전 · 적재일 · 적재처 · 상태)
│                     #   제목은 원본 파일명(확장자 제외)과 정확히 같게 — ledger가 이걸로 대조한다. 상태는 마지막 열
├── manifests/<배치id>.json  # 기계가 만든 발견 목록 (정산의 독립 기준점)
├── updates.md        # 배치별 갱신 로그 (배치 id = <날짜>-<소스 약칭> · 정산 · 실패/격리/보류 목록)
├── md/<문서id>.md    # 게이트를 통과한 변환 마크다운
├── quarantine/<문서id>.md  # 격리 산출물 — 삭제하지 않는다 (재시도 대상이자 증거)
└── meta/<문서id>.json # 출처 경로·날짜·원본 확장자·변환기@버전·확실도·품질 판정·content_hash
```

- **문서id** = 원본 파일명(확장자 제외) + `-` + **원본 파일** sha256 앞 8자.
- **content_hash** = 변환 후 마크다운의 sha256 (index.md·meta의 해시 열은 이것).
- **상태** 열은 `적재 | 실패 | 건너뜀 | 격리 | 보류` — 전부 행을 얻는다. 색인은 배치의
  전체 기록이지 성공 목록이 아니다.
- md·txt·csv처럼 변환 없는 포맷도 내용 그대로 `md/<문서id>.md`로 저장하고,
  원본 확장자는 meta에 기록한다.

## Workflow (배치당 최대 50개 파일)

0. **게이트 확인** — 배치 시작 전에 `scripts/verguard.py`로 게이트 무결성을 확인한다.
   봉인과 다르면 멈춘다 — 게이트를 고쳤다면 그것은 스킬 버전업이지 이번 배치의 일이 아니다.
   **검사기가 없으면 배치를 시작하지 않는다**(보류로 보고). 손으로 대행하는 것은
   게이트 부재를 게이트 통과로 바꾸는 일이다.
1. **수집·판별** — 지시받은 소스만 나열한다. 지시 없는 폴더는 열지 않는다.
   **발견은 기계가 센다**: `scripts/manifest.py <배치id> <소스> --out <기준폴더>/ingestiger/manifests`
   가 소스를 나열해 경로·해시를 매니페스트로 고정하고, 상한 50 초과분을 이월로 분리한다.
   사람이 신고한 발견 수는 정산의 기준이 될 수 없다 — 발견 단계에서 조용히 빠진 파일은
   색인과 신고 수가 함께 짧아져 등식이 완벽히 맞아버린다.
   형식은 **확장자가 아니라 매직바이트로 판별한다**(`scripts/sniff.py`) — 확장자와 실체가
   다른 파일(문서로 위장한 XML, MIME 내보내기, .doc으로 위장한 xls 등)은 실체 형식의
   경로로 보내거나, 경로가 없으면 실패(사유 `형식 위장`)로 보낸다.
   재발견 파일의 멱등 판정은 `scripts/idem.py`.
2. **변환** — 아래 라우팅 표대로 마크다운화한다. 이미 텍스트인 포맷(md, txt, csv)은
   변환 없이 그대로 쓴다. 변환 직후 **품질 게이트**(`scripts/qualgate.py`)를 통과시킨다:
   - 깨진 글리프·대체문자가 본문의 눈에 띄는 비율이면 미달 (성공 종료 코드는 증거가 아니다);
   - 문서 분량 대비 추출 글자 수가 비정상적으로 적으면 미달;
   - 열 밀림·다섯 자리 정수 날짜·`#REF!`·표 붕괴 징후면 미달.
   미달이면 표의 보조 경로(재래스터화 OCR 등)로 1회 재시도하고, 그래도 미달이면 격리.
3. **로컬 저장 + 민감 스캔** — `md/`(또는 격리 시 `quarantine/`)와 `meta/`에 쓴다.
   저장 직후 민감 자동 스캔(`scripts/piiscan.py` 정규식 레이어 + 설치된 환경에서는
   NER 레이어 추가)을 돌리고, 플래그가
   서면 상태를 보류로 표시하고 이 문서의 4·5단계를 멈춘다 — **자동 판정은 보류까지만,
   확정은 사람이 한다.** 제3자(고객사) 소유가 드러나는 문서는 스캔과 무관하게 건너뜀.
   `index.md` 행은 배치 종료 시 문서마다 최종 상태와 함께 1행씩 추가한다.
4. **미러 (지시 시)** — 구글 드라이브 또는 선택 DB로 로컬 정본을 복사한다. 보류·격리
   문서는 미러하지 않는다. DB 미러의 청킹은 5단계와 같은 규칙. 결과는 미러 버킷으로 센다.
5. **적재** — 코퍼스/RAG 저장소에 넣는다. 저장소는 호출 환경의 도구 배선이 정한다 —
   후보가 없거나 여럿이면 지어내지 말고 호출자에게 묻는다. 청크는 변환기가 구조 청크
   (헤딩 위계·표 독립)를 제공하면 그것을 쓰고, 없으면 문단 단위 500~1000자. 문서마다
   출처 경로·날짜·변환기@버전 메타를 함께 남긴다.
   **노드 생성**: 저장소가 노드 색인(키워드·그래프 축)을 벡터 색인과 따로 가지면,
   문서마다 문서 노드를 함께 만든다 — 제목·요약(검색어가 걸리도록 핵심 값 포함)·출처
   경로·확실도를 속성으로. 벡터에만 넣으면 키워드·그래프 축이 빈 채 하이브리드 검색이
   반쪽으로 돈다. 핵심 값이 뚜렷한 문서는 증거(원문 단위)→개념·주장 경로도 보강한다 —
   노드·엣지에도 근거(원본 좌표)·확실도를 남긴다. 저장소의 문법(스페이스·노드 타입·
   관계)은 서버 조회가 정본이다.
6. **검증** — 두 겹이다.
   - **역추적**: 적재된 값 3건을 원본 좌표까지 되짚는다. 좌표는 `<파일>:<위치>` 꼴 —
     표는 `<시트>:<행>`, 문서는 페이지·절, 음성은 `mm:ss`.
   - **스모크 질의**: 새로 적재한 문서마다 제목이나 핵심값으로 1질의를 던져 top-k 적중을
     확인한다. **소비자가 실제로 쓰는 질의 표면으로** 던진다. 저장소가 여러 축(벡터·키워드·
     그래프)을 합성한다면 축별로 따로 확인한다 — 한 축이 비어 있어도 다른 축이 결과를
     내면 가려진다. 질의 세트의 정본은 기준 폴더의 `golden.md`(부재 판정 함정 문항 포함).
     **문항은 변환 산출물이 아니라 원본에서 뽑는다** — 방금 색인에 넣은 문장으로 질의를
     지으면 적중은 항등식이 된다. 가능하면 소비자나 별도 세션이 출제하고, 결과를
     updates.md에 남긴다.
   - **정산 기계 검증**: `scripts/ledger.py <기준 폴더>/ingestiger --manifest <배치>.json`
     — 매니페스트와 **소스 폴더를 지금 다시 읽어** 대조하고(침묵 누락 탐지), 매니페스트
     항목이 색인에 전부 기록됐는지, 배치 단위 상태 합계가 발견 수와 맞는지, 적재·격리
     행의 파일이 문서id로 실재하는지 판정한다. 미완이면 배치를 끝내지 않는다.
   - **역추적 표본은 고르지 않는다**: 되짚을 3건은 content_hash 오름차순 앞 3건처럼
     결정적 규칙으로 정한다. 표본 선택권은 곧 채점권이다.
7. **보고** — `updates.md`에 배치 로그를 남기고, 출력 형식대로 보고한다.

| 적재·검증 | 코퍼스 저장소의 ingest·query 도구 | 도구 목록의 정본은 이 표가 아니라 서버다 — 실제 목록을 조회해 확인한다 |

## Rules

이 스킬은 홀로 설치돼도 돌아가야 하므로 아래에 게이트 요지를 담는다.
**작업 환경에 `config/guides/corpus-gates.md`가 존재하면 그 원문이 우선한다**
(그 파일의 존재가 soloforce 계열이라는 판별 기준이다) — 첫 작업 전에 읽고,
이 절과 다르면 그쪽을 따른다.

- **원본은 읽기 전용.** 수정·이동·삭제하지 않는다. 산출물은 변환의 결과다.
- **지어내지 않는다.** 변환·읽기에 실패한 파일은 실패 목록에 그대로 올린다.
  조용히 빠진 파일이 가장 위험하다 — 정산이 안 맞으면 미완이다.
- **멱등성.** 같은 배치를 다시 돌려도 색인 행과 코퍼스 문서가 늘지 않아야 한다.
  판단 기준은 색인의 원본 해시 + 변환기@버전: 둘 다 같으면 건너뜀(`불변`),
  원본 해시가 다르면 재변환·갱신, 변환기 버전만 올랐으면 재변환 대상이다.
- **미상은 `미상`으로.** 읽지 못한 값은 공백도 추측도 아닌 `미상`으로 기록한다.
- **근거·확실도.** 이미지·음성처럼 판독으로 읽은 값에는 어디서 읽었는지(근거)와
  확인/추정(확실도)을 함께 남긴다.
- **3회 격리 원칙.** 3회 시도해도 통과 못 하는 단위는 붙잡지 말고 다음으로 간다 —
  실패(사유 `재시도 소진`)로 세고 경로를 올린다. 품질 미달로 내용이 남은 단위는
  격리 버킷·`quarantine/`으로 — 격리물은 지우지 않는다(다음 배치의 재시도 목록이다).
- **민감 판정.** "이게 의도치 않은 사람에게 보이면 누가 손해를 보나" — 답이 나오면
  그 문서·값은 건너뛰고 **경로만** 보고한다. 내용은 어느 저장 계층에도 옮기지 않는다.
  자동 스캔은 이 판정의 그물이지 판정자가 아니다 — 플래그는 보류, 확정은 사람.
- **고객사(제3자) 자료는 어느 적재처에도 넣지 않는다.** 코퍼스가 단일 테넌트 공유
  저장소라면 넣는 순간 사후 격리가 불가능하다. 판별은 지시·폴더명·문서 내용으로
  제3자 소유가 드러나는지로 하고, 애매하면 넣지 말고 묻는다.
- **게이트를 약화시키지 않는다.** 통과시키려고 검사를 느슨하게 바꾸는 것은 미통과를
  완료로 보고하는 것과 같다. `scripts/`의 검사기들이 게이트의 실행체다 — 판정이 마음에
  안 들면 산출물을 고치지, 스크립트를 고치지 않는다. 스크립트 수정은 스킬 버전업이며,
  `gates.sha256` 봉인을 다시 찍어야 한다(0단계가 그 차이를 잡는다).
- **검사기가 검증하는 것은 자기 장부가 아니라 바깥 진실이어야 한다.** 정산의 기준점은
  기계가 만든 매니페스트와 소스 폴더 재나열이고, 스모크 문항은 원본에서 나오며,
  역추적 표본은 규칙이 지정한다. 세 가지가 다 자기 산출물이면 그 검증은
  "이야기를 모순 없이 유지하는 능력"을 잴 뿐이다.
- **스키마·색인 구조를 마음대로 만들거나 바꾸지 않는다.** 없거나 다르면 멈추고 올린다.
- **지시 없는 폴더는 열지 않는다.** 배치 상한 50을 넘기지 않는다.
- 예시는 항상 일반형(`<파일>:<시트>:<행>`)으로 남긴다 — 실제 값은 보고서에만.

## Verification

배치를 끝내기 전에 확인한다:

1. **정산 일치**: 발견 = 적재 + 실패 + 건너뜀 + 격리 + 보류 (버킷 정의는 Goal 절).
   기준은 매니페스트이며 `ledger.py`가 소스 재나열까지 대조한다. 미러 버킷도 합이 맞는다.
2. **역추적 3건**: 적재된 값 3건이 원본 좌표까지 되짚어지고 그 좌표가 보고에 있다.
3. **색인 정합**: `index.md` 행 수 증가분 = 발견 수, 상태 열 합계가 정산과 일치.
   `updates.md`에 배치 로그 존재. 격리 문서마다 `quarantine/` 파일이 실재한다.
4. **스모크 질의**: 새로 적재한 문서가 실제 질의 표면에서 top-k 적중한다 — 단, 이것은
   검색 가능성 확인이지 값이 맞다는 증거가 아니다(그 증거는 2번이다).
5. **미러 확인 (미러했다면)**: `scripts/mirrorcheck.py <기준폴더>/ingestiger --emit`으로
   미러가 담아야 할 목록(경로·크기·해시, `quarantine/` 제외)을 만들고, 원격이 신고한
   목록을 `--expect`로 대조한다 — 눈으로는 "있어야 할 것이 없는" 누락이 보이지 않는다.
   DB 미러는 문서 수와 문서별 content_hash 메타가 일치하면 된다(청크 수는 저장소 몫).
   보류·격리 문서가 미러에 없음을 확인한다.
