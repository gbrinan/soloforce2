# 📰 [2026-10-16] AI 업데이트 다이제스트

> 🔵 Anthropic이 METR에 "직원급" 접근권을 부여해 외부 평가자가 자사 리스크 수준을 독립적으로 검증·공개할 수 있게 했다. AI 안전 거버넌스에서 은행 감독관 모델을 업계 표준으로 밀어붙이는 움직임이다.

## Anthropic/Claude

**독립 평가자에게 "직원급" 접근권 부여** — Anthropic이 10월 15일, 비영리 평가기관 METR의 6인 팀에 자사 리스크 평가팀과 비슷한 수준의 하드웨어·사무공간·내부 툴 접근권을 부여했다고 발표했다. METR은 고객 데이터·법적 특권 정보·모델 아키텍처 세부사항 등 좁은 범주를 제외하면 Anthropic 내부 정보를 자유롭게 받아볼 수 있고, Anthropic의 사전 승인 없이 리스크·사고·관행에 대한 분석을 공개할 수 있다(Anthropic은 정해진 범주 내에서만 수정을 요청 가능). SecureBio(화학·생물무기 챕터 검토), Accenture·Faculty(레드티밍·정렬 평가)와의 협업도 심화 중이며 Hugging Face와는 초기 논의 단계다. 백악관의 "슈퍼인텔리전스 협약" 공약 이행의 일환으로, Anthropic은 이 은행 감독관식 모델을 모든 프런티어 AI 기업이 채택해야 할 업계 표준으로 제시한다.
공식 발표: https://www.anthropic.com/news/an-update-on-independent-evaluators

**싱가포르 사무소 개소 + 정부 MOU 체결** — 10월 14일 Anthropic이 APAC 5번째 사무소를 싱가포르에 열고, 싱가포르 디지털개발정보부(MDDI)와 AI 안전·보안·모델평가 협력을 위한 MOU를 체결했다. 서명은 Permanent Secretary Kai Fong Chng와 Anthropic 공동창업자 Ben Mann이 Singapore International Cyber Week에서 진행했고, Josephine Teo 장관이 입회했다. GovTech(엔지니어 1,500명 이상이 Claude Code 사용), DBS, GIC, Grab, Sea(Shopee) 등이 이미 Claude를 도입했고, Anthropic Economic Index 기준 싱가포르는 인구 대비 Claude.ai 사용량이 121개국 중 2위다. 정부 차원의 AI 안전 협력과 동남아 시장 공식 거점 확보라는 점에서 조직·파트너십 발표로 중요하다.
공식 발표: https://www.anthropic.com/news/singapore-office-opening

## xAI/Grok

**Grok Voice 3.0 출시** — 10월 14일 xAI가 Voice Agent API용 신규 음성모델 Grok Voice 3.0을 출시했다. Artificial Analysis의 독립 Speech-to-Speech Index에서 86.9점으로 OpenAI GPT-Live-1, Google Gemini 3.8 Live를 제치고 1위에 올랐다. 가격은 분당 $0.08로 기존 Voice 2.0과 동일하게 유지했지만, API 측면에서는 실질 변경이 있다: `grok-voice-latest` 별칭이 신모델로 이전되고 `grok-voice-2.0`은 지원 종료(EOL) 예정이며, 기존 Voice Agent API 고객은 자동 마이그레이션됐다. 신모델 출시와 구체적인 API 지원 종료·마이그레이션을 동반한 사례라 중요하다.
공식 발표: https://x.ai/news/grok-voice-3
